Motion behavior draws on Kinetics by **ckissi / Colorion** ([gallery](https://kinetics.colorion.co/), [repository](https://github.com/ckissi/kinetics)), packaged reference commit `017498f8ae0e728ce7461852070d22601dd0a46e`. Depth Stack provided a reference for restrained scale and translation. The final reading stack independently adapts those depth cues to native scroll position instead of hover, overlapping cards, or a dial. Direct response and interruption follow Apple Design.

The user-preferred original dry tick uses a 22 ms decaying procedural-noise burst, a 1.7 kHz band-pass filter, and a 25 ms gain envelope. Only scroll-driven article focus changes produce sound; other interface actions are silent. Sound Design guides consent, timing, voice limits, and mute/visibility handling. No reference recordings, tonal melody, samples, or network audio are used. Subjective auditory review is not claimed.
