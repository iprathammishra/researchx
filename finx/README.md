# finx

A minimal field guide to AI × finance: CFA preparation, applied projects, career moves and better business decisions.

**[Read finx →](https://iprathammishra.github.io/researchx/finx/)**

Short articles, an adjustable 2027 CFA planner, original sketches and decision graphs. Sources and image credits sit beside the content.

Part of researchx. Run `npm run build` and `npm run preview` from the repository root, then open `/finx/`.

All environments use researchx `master`. GitHub Pages publishes the collection and this guide together.
